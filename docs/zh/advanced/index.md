# 进阶

进阶部分收录**主线教程之外**、但在实际项目中经常遇到的主题。和主线不同，这里的每个主题相对独立，可以按需阅读——前提是你已经完成了主线教程。

::: info 技术细节
进阶内容会在主线完成后陆续编写。下面是目前的规划，顺序不代表发布顺序。
:::

## 已有内容

- [数据库迁移](./efcore-migrations)：给已有表增加字段，并验证旧数据没有丢失。

## 规划中的主题

| 主题 | 解决什么问题 |
| --- | --- |
| 后台任务 | 请求返回之后继续执行的工作：定时任务、队列消费（`BackgroundService`） |
| 缓存 | 用内存缓存、分布式缓存与输出缓存减少重复计算和数据库压力 |
| 限流 | 保护接口不被过量请求压垮（内置的 Rate Limiting 中间件） |
| 实时通信 | 用 SignalR 向客户端主动推送消息 |
| 健康检查 | 让负载均衡器和容器编排平台知道你的服务是否正常 |
| 原生 AOT | 把应用编译为原生可执行文件，获得更快的启动速度和更小的内存占用 |
| 可观测性 | 用 OpenTelemetry 收集链路追踪和指标 |

如果你特别希望看到某个主题，欢迎在仓库中提交 Issue。
