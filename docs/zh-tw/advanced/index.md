# 進階

進階部分收錄**主線教學之外**、但在實際專案中經常遇到的主題。和主線不同，這裡的每個主題相對獨立，可以按需閱讀——前提是你已經完成了主線教學。

::: info 技術細節
進階內容會在主線完成後陸續編寫。下面是目前的規劃，順序不代表發佈順序。
:::

## 已有內容

- [資料庫遷移](./efcore-migrations)：給已有表增加欄位，並驗證舊資料沒有丟失。

## 規劃中的主題

| 主題 | 解決什麼問題 |
| --- | --- |
| 背景任務 | 請求回傳之後繼續執行的工作：定時任務、佇列消費（`BackgroundService`） |
| 快取 | 用記憶體快取、分散式快取與輸出快取減少重複計算和資料庫壓力 |
| 限流 | 保護 API 不被過量請求壓垮（內建的 Rate Limiting 中介軟體） |
| 即時通訊 | 用 SignalR 向用戶端主動推送訊息 |
| 健康檢查 | 讓負載平衡器和容器編排平臺知道你的服務是否正常 |
| 原生 AOT | 把應用程式編譯為原生可執行檔案，獲得更快的啟動速度和更小的記憶體佔用 |
| 可觀測性 | 用 OpenTelemetry 收集鏈路追蹤和指標 |

如果你特別希望看到某個主題，歡迎在儲存庫中提交 Issue。
