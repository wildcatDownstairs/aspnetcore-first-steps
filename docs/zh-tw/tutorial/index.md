# 學習路線

這套教學是**一條線性的主線**，不是一本可以隨意翻閱的參考手冊。每一章都建立在前面章節的基礎上：

- 「請求與回應」裡學到的參數繫結，是後面所有 API 的基礎；
- 「資料存取」要用到「應用程式骨架」裡的相依性注入和設定；
- 「安全」中的身分驗證與授權，本質上是在中介軟體管道裡插入的環節。

所以請**按順序閱讀**。每一章對應儲存庫 `samples/` 目錄下一個獨立、完整、可執行的專案，你隨時可以開啟對應的範例和自己的程式碼對照。

## 每一頁怎麼讀

每一頁都遵循相同的結構，熟悉之後你會讀得很快：

1. **完整程式碼**：頁面開頭就給出本節最終的完整程式，可以先複製執行，看看效果；
2. **執行與驗證**：給出執行指令和預期輸出，確認你的環境和結果都沒問題；
3. **逐段拆解**：高亮本節新增或變化的行，逐一解釋它做了什麼、**為什麼**這樣設計；
4. **總結**：用幾條要點回顧本節內容，並連結到下一頁。

頁面中會出現四種提示框，含義是固定的：

:::

:::
