# 応用

応用編では、**メインのチュートリアルには含まれないものの**、実際のプロジェクトでよく使われるテーマを取り上げます。メインの学習ルートとは異なり、各テーマは比較的独立しているため、必要に応じて読めます。ただし、先にメインのチュートリアルを完了してください。

::: info 技術詳細
応用編の内容は、メインのチュートリアルの完了後に順次執筆する予定です。以下は現在の計画であり、掲載順が公開順を表すものではありません。
:::

## 公開済みの内容

- [データベースのマイグレーション](./efcore-migrations)：既存のテーブルに列を追加し、既存データが失われていないことを確認します。

## 今後取り上げるテーマ

| テーマ | 解決する課題 |
| --- | --- |
| バックグラウンド処理 | リクエストへの応答後も続けて実行する処理：定期実行、キューの消費（`BackgroundService`） |
| キャッシュ | メモリキャッシュ、分散キャッシュ、出力キャッシュを使い、重複計算やデータベースへの負荷を減らす |
| レート制限 | 過剰なリクエストでエンドポイントが停止しないように保護する（組み込みの Rate Limiting ミドルウェア） |
| リアルタイム通信 | SignalR を使ってクライアントへメッセージをプッシュする |
| ヘルスチェック | サービスが正常かどうかをロードバランサーやコンテナーオーケストレーション基盤に知らせる |
| Native AOT | アプリケーションをネイティブ実行可能ファイルにコンパイルし、起動を速く、メモリ使用量を小さくする |
| オブザーバビリティ | OpenTelemetry で分散トレースとメトリクスを収集する |

取り上げてほしいテーマがあれば、リポジトリに Issue をお寄せください。
