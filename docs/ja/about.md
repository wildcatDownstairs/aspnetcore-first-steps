# このチュートリアルについて

## 対象読者

本チュートリアルは、**プログラミング経験はあるものの、C# や ASP.NET Core を書いたことがない**開発者向けです。Python（FastAPI、Flask、Django）や Node.js を使ったことがある方、または主にフロントエンドを担当している方を想定しています。メインの学習ルートを終えると、データベースと認証を備え、デプロイできる Web API を自力で作れるようになるはずです。

## 技術範囲

- **.NET 10（LTS）と C# 14**：すべてのコードは .NET 10 の書き方に基づいており、`Startup.cs` などの旧来のパターンは扱いません。
- **Minimal API のみ**：MVC Controller、Razor Pages、Blazor は扱わず、学習の流れを一つに絞っています。
- **EF Core + SQLite**：データベースを別途インストールする必要はありません。リポジトリをクローンすれば実行できます。
- **組み込み OpenAPI + Scalar**：すべてのサンプルに、対話型 API ドキュメントが付属します。

## 執筆方針

- **1ページにつき新しい概念を一つだけ紹介します**。ページの冒頭に完成したコードを示し、その後に部分ごとに解説します。
- **コードはすべてそのまま実行できます**。チュートリアルのコードはリポジトリの `samples/` ディレクトリにある実際のプロジェクトから引用しており、ドキュメントに手書きしたものではありません。継続的インテグレーション（CI）ではコミットのたびにすべてのサンプルをビルドし、一つでもビルドに失敗すると公開できない仕組みです。
- **「使い方」だけでなく「なぜ」そうするのかも説明します**。
- **期待される出力を示し、正しくできたか確認できるようにします**。

本チュートリアルの構成と教え方は FastAPI の公式チュートリアルに着想を得ていますが、文章とサンプルはすべて独自に作成したものです。
