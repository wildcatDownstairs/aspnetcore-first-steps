# 学習ロードマップ

このチュートリアルは、**自由にページをめくるリファレンスではなく、順序立てた一続きの学習ルート**です。各章は前の章の内容を土台にしています。

- 「リクエストとレスポンス」で学ぶパラメーターのバインドは、以降のすべてのエンドポイントの基礎です。
- 「データアクセス」では、「アプリケーションの骨格」で学ぶ依存性注入と構成を使います。
- 「セキュリティ」で扱う認証と認可は、ミドルウェアパイプラインに組み込む仕組みです。

そのため、**順番に読んでください**。各章にはリポジトリの `samples/` ディレクトリにある、独立して実行できる完成したプロジェクトが対応しています。いつでもサンプルを開いて、自分のコードと比較できます。

## 各ページの読み方

すべてのページが同じ構成になっているので、慣れるとすばやく読めます。

1. **完成したコード**：ページの冒頭にこの章の完成プログラムを掲載しています。まずコピーして実行し、結果を見ることができます。
2. **実行と確認**：実行コマンドと期待される出力を示します。環境と結果に問題がないか確認できます。
3. **部分ごとの解説**：この章で追加または変更した行をハイライトし、それぞれの処理と、**なぜ**その設計になっているのかを説明します。
4. **まとめ**：重要なポイントをいくつか振り返り、次のページへのリンクを掲載します。

ページ内に登場する4種類の案内ボックスは、次の意味で使われています。

::: tip ヒント
実用的なコツを紹介し、遠回りを避けられるようにします。
:::

::: info 技術詳細
内部の仕組みを説明します。初めて読むときは飛ばしても、続きの内容には影響しません。
:::

::: warning 注意
よくある落とし穴を紹介します。必ず読むことをおすすめします。
:::

::: fastapi FastAPI との比較
FastAPI を使ったことがある方に、対応する概念を1、2文で説明します。使ったことがなくても問題ありません。その場合は読み飛ばしてください。
:::
