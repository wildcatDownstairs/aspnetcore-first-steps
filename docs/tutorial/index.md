# 学习路线

这套教程是**一条线性的主线**，不是一本可以随意翻阅的参考手册。每一章都建立在前面章节的基础上：

- 「请求与响应」里学到的参数绑定，是后面所有接口的基础；
- 「数据访问」要用到「应用骨架」里的依赖注入和配置；
- 「安全」中的认证与授权，本质上是在中间件管道里插入的环节。

所以请**按顺序阅读**。每一章对应仓库 `samples/` 目录下一个独立、完整、可运行的项目，你随时可以打开对应的示例和自己的代码对照。

## 每一页怎么读

每一页都遵循相同的结构，熟悉之后你会读得很快：

1. **完整代码**：页面开头就给出本节最终的完整程序，可以先复制运行，看看效果；
2. **运行与验证**：给出运行命令和预期输出，确认你的环境和结果都没问题；
3. **逐段拆解**：高亮本节新增或变化的行，逐一解释它做了什么、**为什么**这样设计；
4. **总结**：用几条要点回顾本节内容，并链接到下一页。
